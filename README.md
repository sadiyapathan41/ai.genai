# 🤖 AI Document Assistant

An AI-powered chatbot built using **Google Gemini API** that provides fast, accurate, and intelligent responses to user queries. Users can enter their Gemini API key, choose a Gemini model, and interact with the chatbot through a clean and responsive interface.

---

## 🚀 Features

- 💬 AI-powered chatbot using Google Gemini
- 🔑 Secure API key input
- 🤖 Multiple Gemini model selection
- ⚡ Instant AI-generated responses
- 📱 Responsive and user-friendly interface
- 🎨 Clean and modern UI
- 🔄 Real-time question answering

---

## 🛠️ Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Gemini API
- Gemini Flash Lite Model

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/your-username/AI-Document-Assistant.git
```

2. Open the project folder

```bash
cd AI-Document-Assistant
```

3. Open `index.html` in your browser.

4. Enter your **Google Gemini API Key**.

5. Start asking questions!

---

## 🔑 Getting a Gemini API Key

1. Visit Google AI Studio
2. Create a free API key.
3. Paste the API key into the application.
4. Select a Gemini model.
5. Enjoy chatting with AI!
